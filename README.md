# Dr. Marcelo Vasconcelos — Mentoria Empresarial para Médicos

Landing Page de alta conversão voltada para médicos proprietários de clínicas e consultórios, desenhada especificamente para campanhas de tráfego pago (Meta Ads / Google Ads).

## 🎯 Objetivo
Converter médicos qualificados em solicitações de diagnóstico estratégico e reuniões online de 30 minutos com o time do Dr. Marcelo Vasconcelos.

## 🚀 Arquitetura e Funil
`Anúncio → Landing Page → VSL → Formulário de Qualificação → Reunião Comercial (30 min)`

- **Seção 01 — Hero com VSL**: Headline editorial de alto padrão, player de vídeo cinematográfico com modal e CTA verde neon com pulso.
- **Seção 02 — Prova Social**: Resultados reais de médicos especialistas (Ortopedia, Dermatologia e Cirurgia Plástica).
- **Seção 03 — Como Funciona o Diagnóstico**: Bloco editorial em estilo consultoria de elite com quebra visual off-white (`#F5F3ED`).
- **Seção 04 — Para Quem É Indicado**: Qualificação e filtros estratégicos.
- **Seção 05 — FAQ**: Accordion interativo para objeções comuns.
- **Seção 06 — CTA Final + Formulário Integrado**: Captação de dados, qualificação de faturamento/desafios e redirecionamento direto para o WhatsApp da equipe.

## 🎨 Paleta e Tipografia
- Preto profundo: `#050505`
- Off-white editorial: `#F5F3ED`
- Dourado champagne: `#C9A96A`
- Verde neon (CTA): `#8DFF00`
- Títulos: *Playfair Display*
- Textos: *Plus Jakarta Sans*

## 🛠️ Tecnologias
- HTML5 Semântico com meta tags OpenGraph
- CSS3 moderno (Custom properties, CSS Grid, Flexbox, Keyframe Animations)
- JavaScript Vanilla (máscara de telefone, modal de VSL, accordion, validação de formulário)
- Zero dependências externas pesadas (foco em performance LCP < 1s)
